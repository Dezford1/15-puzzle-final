## Processing

Each photo was centre-cropped to a square and resized to 800x800, then
saved as JPEG at quality 86. Square matters: the board is square and
each tile shows one sixteenth of the image, so a rectangular source
would be stretched out of proportion.

## Replacing them

Drop a square JPEG in this folder using the same filename. Nothing in
the CSS or JavaScript needs to change. Roughly 800x800 is the useful
size — the board renders at 520px, so anything larger is wasted bytes.
